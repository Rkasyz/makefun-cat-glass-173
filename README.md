## The entry

One sentence, in a house cat's own voice, spoken in the five seconds after
sweeping a glass off the table. No apology, no confession — just the most
convincing case a cat can make for itself:

> The glass and I had a disagreement about its future, and after a thorough
> inspection from above I concluded it belonged on the floor, where it now
> lives rent-free.

(163 characters — within the 200-character limit.)

## How it works

`main.py` (Python 3.13, standard library only, no network) writes exactly
that sentence to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output`). The
text is fixed and deterministic: every run produces byte-identical output.
